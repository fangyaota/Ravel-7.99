# 3、运算符

## 3.1 算术

`+` `-` `*` 和别家一样；`/` 两边都是整数就是整数除法（`10 / 3` 是 `3`，`10.0 / 3` 才是小数）。

**`%` 是截断余数** —— 和 C / C# 一样，和 Python 不一样：

| 写法 | Ravel | Python |
|------|-------|--------|
| `-7 % 3` | `-1` | `2` |
| `7 % -3` | `1` | `-2` |

一个口径贯穿所有数值类型：`a % b = a - b * trunc(a / b)`。`int` / `bigint` / `float` / 分数都有；除数为零和 `/` 报同一句话。

### 乘方 `**`

**右结合**，而且**比一元负号紧** —— 它是这门语言唯一比一元紧的二元运算符：

| 写法 | 读作 | 交回 |
|------|------|------|
| `2 ** 10` | | `1024`（int）|
| `2 ** 3 ** 2` | `2 ** (3 ** 2)` | `512` |
| `2 ** -1` | `2 ** (-1)` | `0.5`（**float**）|
| `-2 ** 2` | `-(2 ** 2)` | `-4` |
| `(-2) ** 2` | | `4` |
| `2 ** 0.5` | | `1.4142135623730951` |

（对照一下：`-2 * 3` 是 `(-2) * 3` —— 只有 `**` 例外。写 `-2 ** 2` 的人想要 -4 的多。）

**左边是什么类型就在哪个类型里算**：`int ** int` 还是 int，装不下报「大数用 bigint」（和 `*` 一样，不悄悄换成 bigint）；掺了 float 就全程 double。

**整数的负次幂交回 float**（`2 ** -1` 是 `0.5`）—— 整数装不下 `1/2`。**分数不受这条影响**：上下颠倒就行，`(fraction 1 2) ** -1` 还是 `2/1`。

`x **= 2` 和别的复合赋值一样。

#### 实例

```ravel
print (2 ** 10)
print (2 ** 3 ** 2)
print (2 ** -1)
print (-2 ** 2)
print ((fraction 1 2) ** -1)
```

执行以上程序会输出如下结果：

```
1024
512
0.5
-4
2/1
```

## 3.2 比较

`==` `!=` `<` `>` `<=` `>=`。整数和浮点可以混用（`3 == 3.0` 是 `true`）。

相等性的口径和别家不一样：**原子值比值，对象按身份**（类对象、函数、容器都在"对象"这一边）。

#### 实例

```ravel
print (() == ())
print ([1] == [1])
```

执行以上程序会输出如下结果：

```
true
false
```

一边是对象一边不是，就报「不支持操作数」（`[1] == ()`、`C == 5`），**不静默给 `false`**。

`NaN` / `Inf` / `-Inf` 按 IEEE 来：`NaN == NaN` 是 `false`，`1 / Inf` 是 `0`，`Inf - Inf` 是 `NaN`。它们打印成 ASCII 的 `NaN` / `Inf` / `-Inf`（不是 `∞`）。

## 3.3 类型判定 `:`

| 写法 | 交回 |
|------|------|
| `1: int` | `true` |
| `1: float` | **`false`** —— Integer 和 Float 是兄弟，不是子类型 |
| `1: object` | `true` |
| `!(1: int)` | `false` —— 取反另写 `!` |

判据就是类型树上那条 `A <: B`。**类型之间**的关系用 `<:` / `:>`（两边都得是类型对象）：

| 写法 | 交回 |
|------|------|
| `int <: object` | `true` —— A 是不是 B 的子类型 |
| `object :> int` | `true` —— 方向反过来 |
| `int <: int` | `true` —— 自反 |
| `Every <: int` | `true` —— 底类型是所有类型的子类 |

注意：`(typeof 1): int` 是 `false` —— `typeof 1` 求出来的是**类对象** `Integer`，不是 int 值。括号不能省：`typeof 1: int` 会被读成 `typeof (1: int)`，结果是 `Bool`。

`:` 左边是值（`1: int`），这一对两边都得是**类型**。

### 运算符节

`:` 是个**标点**运算符，所以和 `+` 一样，三种写法都成立（取反另写 `!`）：

#### 实例

```ravel
print (1.: int)
print (:.int 1)
print (!(1.: string))
```

执行以上程序会输出如下结果：

```
true
true
true
```

## 3.4 逻辑

`&&` `||` `!`，**真短路**。`&&` / `||` 是特殊结构，不可重载。

## 3.5 位运算

`&` `|` `^` —— 位运算，也可以当逻辑运算（`|` 还兼着函数交替）。三个都可重载。

**移位**看的是那 32 个格子，不检查数值溢出：

| 写法 | 交回 |
|------|------|
| `1 << 4` | `16` |
| `1 << 31` | `-2147483648` —— 位型就是 `0x80000000` |
| `1 << 32` | `0` —— 全丢光了 |
| `(0 - 8) >> 1` | `-4` —— `>>` 是**算术**右移，符号留住 |
| `5 >>> 1` | `-2147483646` —— `>>>` 是**循环**右移，那个 1 转到最上面去了 |

注意：`>>>` 是循环右移，**不是"无符号右移"**。要逻辑右移（补零）用 `Bits.Shr`。

优先级照 C 的脾气：比加减低、比比较高（`1 + 2 << 3` 是 `(1 + 2) << 3`）。移位量得是**非负的 int**；`bigint` 没有固定宽度，`<<` `>>` 照常，循环移位对它明确报错。

## 3.6 字符串

`+` 拼接，`*` 重复（`"ab" * 3` 是 `"ababab"`）。

转义是 `\"` `\\` `\n` `\t` `\r`。**不认识的转义连同反斜杠原样保留**，所以 Windows 路径不用双写：

#### 实例

```ravel
print ("c:\path\file")
```

执行以上程序会输出如下结果：

```
c:\path\file
```

字符串可以跨行，不需要续行符。

### 原始字符串（`"""…"""`）

连着三个引号开头、连着三个引号收尾，**里面一个字符都不动**。给正则和 Windows 路径用。

#### 实例

```ravel
print """C:\path\nope"""
print """a # 不是注释"""
```

执行以上程序会输出如下结果：

```
C:\path\nope
a # 不是注释
```

- **不插值**。要 `${…}` 用普通字符串。
- **内容里写不了 `"""`** —— 碰到连着三个引号就收尾了。

开引号后面直接换行时那个换行不算内容；再按**收尾那三个引号所在行**的缩进，给每行剥掉同样多：

#### 实例

```ravel
sql := """
    select *
    from users
    """
print (sql)
```

执行以上程序会输出如下结果：

```
select *
from users
```

注意：**某一行缩进写浅了会当场报错**（而它又不是空行）—— 不报的话结果是悄悄多出几个空格。

## 3.7 成员运算符访问与运算符节

运算符写成成员，就是**运算符节**：留一个操作数空着，交回一个等那个操作数的函数。

| 写法 | 交回 |
|------|------|
| `1.+` | `(rhs) => 1 + rhs` —— 右操作数留空 |
| `+.2` | `(x) => x + 2` —— 左操作数留空 |

#### 实例

```ravel
add2 := +.2
print (add2 5)
print ((+.(2 * 3)) 10)
```

执行以上程序会输出如下结果：

```
7
16
```

注意：运算符节右边的表达式**只吃一个 primary**（含成员访问），复杂式要自己加括号。

## 3.8 给类定义运算符

类体里直接用符号定义，符号本身就是成员名：

#### 实例

```ravel
Vec ::= class {
    init = () => { x = 0; this; }
    x: int = 0
    + := (o: Vec) => {
        r := Vec ()
        r.x = x + o.x
        r
    }
    == := (o: Vec) => { x == o.x; }
}
a := Vec ()
a.x = 1
b := Vec ()
b.x = 2
c := a + b
print (c.x)
print (a == b)
```

执行以上程序会输出如下结果：

```
3
false
```

| 写法 | 意思 |
|------|------|
| `+ := f` | **定义**这个类的运算符 |
| `+ = f` | **覆盖**从父类层继承来的那个（父类自己不受影响）|

注意：`init` 每个分支都要以 `this` 收尾 —— 构造**交出 init 的返回值**。

类体里没写过的符号就用不了（`a * 2` 报「类型 class 不支持运算符 '*'」）。一元 `!` 和短路 `&&` / `||` 是求值器特判的，**不能**自定义。

## 3.9 调用比运算符**松**

并列的调用（`f a b`）比运算符**松** —— 调用"抓住"它右边那一整条算式。**没有例外**：

| 写法 | 读作 |
|---|---|
| `f 1 + 2` | `f (1 + 2)` |
| `f (1) + 2` | `f ((1) + 2)` |
| `f x.y + 1` | `f (x.y + 1)` |
| `f x: int` | `f (x: int)`（运算符一样被吃）|
| `xs.Count () + 1` | `xs.Count (() + 1)` —— 数完再加一要写 `(xs.Count ()) + 1` |
| `xs.At (0) + 1` | `xs.At ((0) + 1)` —— 取第 0 个要写 `(xs.At (0)) + 1` |

规矩只有一条：**运算符作用在调用结果上，就自己加括号**。

#### 实例

```ravel
print 1 + 2
print "a" + "b"
inc ::= (n: int) => { n + 1; }
print (inc 1 * 5)
```

执行以上程序会输出如下结果：

```
3
ab
6
```

**转换器式调用**（`string x` / `bigint n` / `typeof x`）后面还要接东西时，要括**整个调用**：

#### 实例

```ravel
n := 5
print ("共 " + (string n) + " 个")
```

执行以上程序会输出如下结果：

```
共 5 个
```

注意：写成 `string (n) + " 个"` **不行** —— 按上面那条会被读成 `string ((n) + " 个")`。括住 `n` 没用，要括住**整个 `string n`**。

`<|` 与 `|>`（见 5.5）是把这件事写明白的语法糖：`f <| a + b` 和 `f a + b` 是一回事。

### 跨行：行首写运算符

一行**以二元运算符打头**时，那个换行**不算数** —— 上一句自己接下去：

#### 实例

```ravel
x := 1
+ 2
print x

g := [1 2 3]
|> (xs: list) => { xs.Count (); }
print g
```

执行以上程序会输出如下结果：

```
3
3
```

判据就是**运算符本身**（标点的 `+` `==` `<` …，词形的 `or` / `and`，还有 `??` / `|>`），
所以接着上一行写和写在一行里是同一件事。两条**不接**：

* `;` —— 那是**明写的**分隔符：`y := 1; + 2` 照旧报错；
* **运算符定义** —— `< := f` 那种打头就是运算符，可那是它在定义（`:=` / `::=` / `:` / `=` 四种收尾
  都算），不是接上一行。

接的是**句**，不是行：`print 1` ⏎ `+ 2` 读成 `print (1 + 2)` —— 上面那条"实参吃到运算符为止"
**跨行照吃**。所以"接着上一行"最容易看错的地方也在这儿：想 `print (f 1)` 之后另起一句 `+ 2`，
那本来就不是一句话。

## 3.10 自增 `++` / 自减 `--`

**语句级的糖**，折成 `x += 1` / `x -= 1` —— 折出来就是那条复合赋值，和手写走同一条路。

#### 实例

```ravel
i := 0
while { i < 5; } { i++; }
print i
```

执行以上程序会输出如下结果：

```
5
```

四条和别家不一样的：

- **它不交回值。** `y := x++` 是**语法错误** —— C 里 `y = x++` 拿旧值、`y = ++x` 拿新值，
  那种"看符号写在哪边猜拿到什么"的东西这儿不给。要值就明写：`y := x; x += 1`。
- **前缀不认。** `++x` 报的还是同一句（它只跟在变量或字段后面）。
- **后面得收尾。** `a--b` 会被读成 `a--` 和 `b` 两条语句，而写它的人多半想要 `a - (-b)` ——
  所以直接报错。连写两个负号时中间那个空格不能省（这条和 C 一样）。
- **目标只能是变量或字段。** `c.n++` 行，`(a + b)++` 不行。

折出来的就是一条 `x += 1`，所以只读字段、`by` 属性那些规矩一条都不用在这儿重说。
