## 1.2 定义变量

`:=` 是**定义**，`=` 是**赋值**。

```ravel
a := 42            # 定义，类型推断成 Integer
b: int = 100       # 定义，显式标注
c = 200            # 赋值 —— 变量必须已经存在，否则报「无法给未定义变量 'c' 赋值」
```

赋值是个**表达式**，交出去的就是赋进去的那个值：

```ravel
x := 1
print (x = 5)      # 5 —— 而且 x 真的变成 5 了
print x            # 5
```

变量的 `:=` 是**语句**，不能塞进表达式（`print (y := 6)` 报「变量的定义（':='）是语句」）。

注意：成员定义（`a.def := 6`）倒是表达式 —— 字段没有"语句"这一说。

## 1.3 自动命名

`::=` 定义变量，并把变量名自动填进 `FunctionVal.Name`（只对函数和类有效）：

```ravel
add ::= (x: int) => { x + 1; }
add.name           # "add"
```

## 1.5 打印和输入

| 写法 | 意思 |
|------|------|
| `print x` | 输出，**带换行**（`System.WriteLine` 的别名）|
| `System.Write x` | 输出，**不带换行** |
| `input ()` | 读一行输入 |

注意：`input ()` 要真终端 —— 从标准输入读一行，脚本里跑会一直等。
