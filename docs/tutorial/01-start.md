## 1.2 定义变量

`:=` 是**定义**，`=` 是**赋值**。

| 写法 | 意思 |
|------|------|
| `a := 42` | 定义 `a`，类型推断成 Integer |
| `b: int = 100` | 定义 `b`，显式标注 |
| `c = 200` | 赋值 —— 变量必须**已经存在** |

#### 实例

```ravel
a := 42
b: int = 100
print [a b]
```

执行以上程序会输出如下结果：

```
[42 100]
```

对没定义过的变量用 `=` 会报错：

#### 实例

```ravel
c = 200
```

执行以上程序会输出如下结果：

```
Error: 无法给未定义变量 'c' 赋值
```

### 赋值是个表达式

赋出去的就是**赋进去的那个值**（变量和字段一个样）。

#### 实例

```ravel
x := 1
print (x = 5)
print x
```

执行以上程序会输出如下结果：

```
5
5
```

变量的 `:=` 是**语句**，不能塞进表达式：

#### 实例

```ravel
print (y := 6)
```

执行以上程序会输出如下结果：

```
Error: 变量的定义（':='）是语句，不能当表达式用（赋值才是：'='）
```

注意：成员定义（`a.def := 6`）倒是**表达式** —— 字段没有"语句"这一说。

## 1.3 自动命名

`::=` 定义变量，并把变量名自动填进 `FunctionVal.Name`（只对函数和类有效）。

#### 实例

```ravel
add ::= (x: int) => { x + 1; }
print add.name
print (add 1)
```

执行以上程序会输出如下结果：

```
add
2
```

## 1.5 打印和输入

| 写法 | 意思 |
|------|------|
| `print x` | 输出，**带换行**（`System.WriteLine` 的别名）|
| `System.Write x` | 输出，**不带换行** |
| `input ()` | 读一行输入 |

#### 实例

```ravel
print "hello"
System.Write "no newline"
print " —— 接着上面那行"
```

执行以上程序会输出如下结果：

```
hello
no newline —— 接着上面那行
```

注意：`input ()` 要**真终端** —— 它从标准输入读一行，脚本里跑会一直等。
